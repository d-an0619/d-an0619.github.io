Privacy Policy

Review Exporter for Amazon (Chrome extension). Last updated 2026-11-22.

  • All processing happens locally in your browser. Reviews are never sent to our servers, and we operate no server that stores reviews.
  • The extension makes network requests only to: amazon.com (the pages you are exporting, using your own session), the extension's configuration file URL (parsing rules, no personal data), and the Gumroad license API (your license key, to validate your license).
  • Stored locally via chrome.storage: your license key and a cached copy of the configuration.
  • No account, no analytics, no ads, no remote code (only data rules are downloaded).
  • Permissions: activeTab, storage, downloads, and access to https://www.amazon.com/* and https://api.gumroad.com/*.
